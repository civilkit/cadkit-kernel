# Dead ends and failed attempts

What was tried, what it showed, and why it was not kept. Read this before trying the same thing again; add an entry when an attempt is
abandoned (what, the measurement, the date, the commit or doc where the detail lives). Numbers are from the date given and the
machine named; the CI box is an old 8-core server and was often at a load of 20 to 80, so compare CPU time, not wall time.
